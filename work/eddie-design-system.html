Design System

Reusable foundations for a product moving faster than its visual rules.

Role
Lead UX/UI Designer
Focus
Foundations · components · handoff
System
4 Figma libraries
Scale
150+ components

Challenge

The product was scaling faster than its rules.

Spacing, components, and interaction patterns were drifting across products. A visual cleanup wouldn’t fix a system problem.

Approach

Build infrastructure, not another UI file.

I created shared foundations for type, color, spacing, grids, accessibility, and responsive behavior, then built production-ready components with real states and edge cases.

Impact

Faster decisions. More consistent output.
